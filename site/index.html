Arquitetura Concêntrica

Um Harness Dentro do Outro, Dentro do Outro...

Como a tradicional boneca russa Matryoshka, cada camada de governança encapsula a próxima. Role para baixo para abrir as cascas concêntricas:

Camada Ativa Atual
L1 ORACLE
Casca Externa • Camada 5

Servidor MCP Nativo (baba mcp serve)

Conecta-se diretamente ao Cursor, Zed, Claude Code e Gemini CLI via stdio padrão. Expõe ferramentas em tempo real (detect_stack, wrap_context, generate_agents) e recursos sem poluir o sistema de arquivos. 

# Auto-wire all IDEs in one second:
baba mcp wire --targets cursor,gemini,claude
Segunda Casca • Camada 4

Motor AST Poliglota (baba wrap)

Parser sintático em WebAssembly Tree-sitter varrendo TypeScript, Python e Go em < 200ms. Elimina testes falsos sem asserção, injeção dinâmica de SQL e credenciais hardcoded antes do push. 

# Deep AST audit & DIAGNOSTIC.md compiler:
baba wrap --strict --threshold 80
Terceira Casca • Camada 3

AGENTS.md Adaptativo & Skills Modulares

Combate a crise de inchaço de contexto. Compila um AGENTS.md raiz ultraleve (< 200 tokens) com regras inegociáveis, roteando diretrizes especializadas para .agents/skills/*.md sob demanda com YAML frontmatter. 

# Compile lean boundary without touching disk:
baba agents generate --dry-run
Quarta Casca • Camada 2

Integração com o Grafo Semântico de Código

Cruza caminhos estáticos de arquivos com o grafo de conhecimento da base de código (codebase-memory-mcp). Mapeia rotas, serviços e fluxo de chamadas antes de qualquer alteração cirúrgica do agente. 

# Inspect project seams and active skills:
baba agents profile
O Núcleo • Camada 1

Oráculo de Maturidade do Repositório (L1 - L4)

Mede a higiene estrutural fundamental (gates de CI, licença, suíte de testes, blueprint de arquitetura) impulsionado pelo oráculo canônico paladini/harness-score e gera badges SVG oficiais de conformidade. 

# Audit structural hygiene and export badge:
baba scan --badge ./harness-badge.svg
Rigor de Engenharia

As Garantias Anti-Slop

Agentes autônomos de código falham quando o contexto apodrece.
O Matryoshka impõe fronteiras determinísticas:

🛡️

Zero Exfiltração de Código

100% da inspeção de AST e gramáticas Tree-sitter roda localmente na sua máquina via WebAssembly. Zero código sai da sua estação de trabalho.

⚡

Execução Sub-15ms

Compilado com Bun em executáveis nativos standalone únicos. Zero necessidade de toolchains de Python, Rust ou C++ no ambiente host.

🚫

Sem Testes Falsos (False-Greens)

Detecta suítes frágeis cheias de mocks geradas por LLMs que passam no terminal mas não possuem nenhuma asserção comportamental real.
