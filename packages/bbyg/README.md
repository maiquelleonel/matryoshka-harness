# @maiquelleonel/bbyg

> 🛡️ Protective Typosquatting Shell & Forwarding Wrapper for [`@maiquelleonel/matryoshka`](https://www.npmjs.com/package/@maiquelleonel/matryoshka)

This package is an official, lightweight protective forwarding shell published under the `@maiquelleonel` scope. It ensures that invocations of `bbyg` seamlessly resolve and execute the canonical **Matryoshka-Harness** engine.

## 🚀 Instant Usage

Execute on-demand without manual pre-installation via your preferred runner:

```bash
# Direct execution via bunx
bunx @maiquelleonel/bbyg --help
bunx @maiquelleonel/bbyg detect

# Direct execution via npx
npx @maiquelleonel/bbyg --version
npx @maiquelleonel/bbyg wrap
```

## 📦 Canonical Installation

For direct production installations, install the canonical package directly:

```bash
npm install -g @maiquelleonel/matryoshka
# or
bun add -g @maiquelleonel/matryoshka
```
