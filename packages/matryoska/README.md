# @maiquelleonel/matryoska

> 🛡️ Protective Typosquatting Shell & Forwarding Wrapper for [`@maiquelleonel/matryoshka`](https://www.npmjs.com/package/@maiquelleonel/matryoshka)

> **⚠️ Note:** `matryoska` is a common typographical variation of `matryoshka`. This package protects users and automation sandboxes against typosquatting and supply-chain confusion by delegating cleanly to the official package.

This package is an official, lightweight protective forwarding shell published under the `@maiquelleonel` scope. It ensures that invocations of `matryoska` seamlessly resolve and execute the canonical **Matryoshka-Harness** engine.

## 🚀 Instant Usage

Execute on-demand without manual pre-installation via your preferred runner:

```bash
# Direct execution via bunx
bunx @maiquelleonel/matryoska --help
bunx @maiquelleonel/matryoska detect

# Direct execution via npx
npx @maiquelleonel/matryoska --version
npx @maiquelleonel/matryoska wrap
```

## 📦 Canonical Installation

For direct production installations, install the canonical package directly:

```bash
npm install -g @maiquelleonel/matryoshka
# or
bun add -g @maiquelleonel/matryoshka
```
